## DUAL ENGINE ARCHITECTURE

Cubicle supports two categories of agent engines:

### CLI Engines (subprocess wrapping)
For coding tasks. Each CLI agent runs as a subprocess via `asyncio.create_subprocess_exec`. Output is captured as JSON, NOT displayed as raw terminal. Supported CLI agents:
- Claude Code: `claude --print --output-format json -p "task"`
- Codex: `codex --quiet -p "task"`
- Grok, Antigravity (Gemini), Qwen, OpenCode, Crush, Pi
- Any custom CLI agent (user provides the command template)

### API Engines (LiteLLM)
For everything else. Direct API calls with structured output via Instructor. Supported:
- Ollama (auto-detected at localhost:11434)
- Anthropic API (BYOK)
- OpenAI API (BYOK)
- Sarvam-105B (BYOK)
- Groq (BYOK)
- Any OpenAI-compatible endpoint

Users choose per-agent which engine to use during the "Add Agent" flow.

## AGENT PERSONALITY SYSTEM

Every agent has:
- **Traits:** picked from categories (social, work style, humor, habits, social style)
- **Quirks:** freeform text descriptions of unique behaviors
- **Mood:** changes based on task results and social events (neutral, happy, stressed, excited, bored)
- **Voice profile:** language, gender, pace (for Sarvam TTS)

Social behavior runs on Celery Beat scheduler:
- Agent idle > 2 min → coffee break
- Two agents both idle → one walks to the other
- Task complete → celebration
- Agent idle > 5 min + another idle → gossip
- Personality match → flirt attempt
- 6 PM → end-of-day sequence

Speech bubbles are generated by a cheap LLM model (Haiku, Ollama, GPT-4o-mini) with the agent's personality injected into the prompt.

## KEY DESIGN DECISIONS

1. **Web, not Electron.** This is a web app served by the user's server. Access from any device.
2. **3D office is decoration, not navigation.** Users interact with sidebar cards and buttons. The Spline scene is ambient background that makes the product feel alive.
3. **No terminal exposure by default.** CLI engine output is parsed and displayed as structured cards. A "Show raw output" drawer exists for developers.
4. **Progressive disclosure.** Default view shows nothing technical. Settings → Advanced is where engine configs and API keys live.
5. **No jargon.** "Start working" not "Spawn agent worker." "AI model" not "LLM backend."
